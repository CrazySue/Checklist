A **Lista de verificação** é uma aplicação de lista de tarefas que usa a linguagem de design MD3.

---

## ✨ Recursos

- **Ficheiro único**: toda a aplicação é um único ficheiro HTML, com tipos de letra, fonte de ícones e ícone da aplicação totalmente incorporados — basta fazer duplo clique para executar offline;
- **Linguagem de design MD3**: tokens de design MD3 completos, camadas de estado, ripple e animações de easing não lineares;
- **Localização**: suporte para 10 idiomas (简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Русский、Português);
- **Seleção inteligente de ícones**: os ícones são correspondidos automaticamente a partir do item da lista / do nome da lista de verificação (índice de 630+ palavras-chave por idioma);
- **Reposição automática**: quando tudo estiver concluído, pode definir uma reposição automática programada, pronto para um novo dia;
- **Partilha fácil**: exportar / importar ficheiros .checklist (JSON internamente) — os dados nunca se perdem;
- **Adaptação a retrato/paisagem**: barra inferior no modo retrato, barra de navegação à esquerda no modo paisagem;
- **Modo escuro**: segue o sistema / claro / escuro, com transições suaves em toda a interface.

## 🎥 Antecedentes

Hoje em dia, as pessoas têm cada vez mais coisas para fazer — festas de aniversário, filmes com amigos... Por isso, muitas aplicações de calendário já integraram funcionalidades de agenda, para lembrar as pessoas de não se esquecerem dos grandes eventos.

Mas o problema não ficou resolvido: saiu de casa e esqueceu-se do cartão de transporte? Saiu do trabalho e esqueceu-se de entregar o relatório diário? São as "pequenas coisas" que compõem as "grandes coisas" que acabam por atrasar as pessoas.

Por isso, Sue, que tanto sofreu com este problema, decidiu desenvolver uma lista de tarefas para o resolver: a *Lista de verificação* não o vai lembrar das grandes coisas — porque muitas aplicações de calendário fazem isso melhor, e é difícil esquecê-las —, mas permite-lhe organizar numa lista as pequenas tarefas que exigem muitos passos, assinalando cada uma à medida que a conclui, **para nunca mais esquecer de nada**.

## 🛠️ Começar a construir

A *Lista de verificação* é uma 5+ App cuja linguagem de programação é o HTML, empacotada num instalador APK através do HBuilderX.

> [!NOTE]
> Como existem inúmeros métodos e tutoriais para empacotar HTML com o HBuilderX, aqui só está listado o processo de construção simplificado; para mais detalhes, consulte a [documentação do HBuilderX](https://hx.dcloud.net.cn/).

Para empacotar o ficheiro HTML num instalador para o seu sistema operativo, siga estes passos:

1. [Transfira o HBuilderX](https://www.dcloud.io/hbuilderx.html).
2. Crie um novo projeto 5+ App.
3. Substitua o index.html pelo ficheiro HTML que pretende empacotar.
4. Edite no manifest.json as opções que precisar de alterar.
5. Use o empacotamento na nuvem ou offline.
6. Carregue um certificado da aplicação (o empacotamento na nuvem pode usar um certificado da nuvem).
7. Empacote.
